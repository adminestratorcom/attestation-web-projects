# Подготовка к защите

## Короткие вопросы
1. **Что такое HTML?** Язык разметки, который задаёт структуру и смысловое содержание страницы.
2. **Для чего CSS?** Для оформления, расположения элементов, адаптивности и визуальных состояний.
3. **Что такое Flexbox и Grid?** Flexbox удобен для размещения элементов в одном направлении, Grid — для двумерных сеток.
4. **Как работает адаптивность?** Гибкие размеры, перестроение сеток и media queries меняют интерфейс под ширину экрана.
5. **Что такое JavaScript?** Язык, который обрабатывает события, выполняет расчёты, фильтрует данные и меняет DOM.
6. **Что такое валидация?** Проверка пользовательских данных до обработки. В проекте используются `required`, `min`, `max`, `pattern`, `minlength`, `reportValidity()`.
7. **Что такое localStorage?** Хранилище браузера, сохраняющее строки между перезапусками браузера. В проекте оно используется для темы портфолио и результата опроса.
8. **Зачем нужны title и description?** Они кратко описывают страницу поисковым системам и пользователям в выдаче.
9. **Что такое robots.txt?** Инструкция для поисковых роботов о доступе к разделам сайта.
10. **Что такое sitemap.xml?** XML-карта URL сайта, помогающая поисковым системам обнаруживать страницы.
11. **Чем отличается addEventListener от onclick?** `addEventListener` регистрирует обработчик события из JavaScript; `onclick` задаёт обработчик непосредственно в HTML.
12. **Что такое DOM?** Объектное представление HTML-документа, с которым JavaScript может работать.
13. **Зачем нужен `textContent`?** Чтобы вставлять текст в элемент без интерпретации строки как HTML-разметки.
14. **Что такое `setInterval`?** Метод, который повторяет функцию с заданным интервалом; в проекте он обновляет таймер.
15. **Почему формы демонстрационные?** В проекте нет серверного API: проверка происходит в браузере, а отправка и хранение на сервере не реализованы.

## Что уметь показать преподавателю
- Финансы: расчёт сложных процентов, проверка диапазонов, построение списка начислений, переключение тарифов.
- Кафе: фильтрация по `data-tags`, добавление/удаление блюд, пересчёт суммы, проверка даты брони.
- Транспорт: поиск по направлению и дате, демонстрационный обратный отсчёт, расчёт тарифа.
- Социальная помощь: аккордеон, проверка телефона и длины сообщения, подсказки карточек через `title`.
- Образование: смена расписания без перезагрузки, фильтр курсов, подсчёт баллов, `localStorage`.
- Медицина: зависимый список врачей, проверка даты, чек-лист симптомов, FAQ.
- Культура: переключение слайдов, фильтр афиши по категории и дате, стоимость билетов.
- Спорт: расчёт ИМТ, учебная оценка калорийности, таймер старт/пауза/сброс, фильтр занятий.
- Магазин: фильтры каталога, корзина, удаление товара, пересчёт суммы, уведомление.
- Бытовые услуги: проверка занятых слотов через массив, калькулятор цены, добавление отзыва в DOM.
- Портфолио: поиск, тема через `localStorage`, `IntersectionObserver`.

## Честные ограничения
Не утверждать, что демонстрационные формы отправляют заявки, что расписание реально, что бронирование подтверждено или что медицинский калькулятор даёт диагноз. Публикация, Метрика/Analytics и реальные URL требуют отдельных действий и аккаунтов.
