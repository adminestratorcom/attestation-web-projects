# Простое объяснение кода

Этот файл помогает читать главные страницы 11 учебных сайтов.

## Общие английские слова

| Слово | Перевод | Что означает |
|---|---|---|
| function | функция | Набор команд для одной задачи |
| const | постоянная переменная | Имя для значения, которое не переназначают |
| let | переменная | Имя для значения, которое можно менять |
| if | если | Проверка условия |
| else | иначе | Что делать, если условие не подошло |
| return | вернуть / остановить | Завершить функцию или вернуть результат |
| document | документ | Текущая веб-страница |
| getElementById | найти по ID | Найти элемент страницы |
| addEventListener | добавить обработчик | Выполнить команду при событии |
| click | щелчок | Нажатие мышью или пальцем |
| input | ввод | Изменение введённого значения |
| value | значение | То, что введено в поле |
| textContent | текстовое содержимое | Текст внутри элемента |
| Number | число | Преобразовать текст в число |
| Math.pow | степень | Возвести число в степень |
| toFixed | знаки после запятой | Округлить число для показа |
| querySelectorAll | найти все элементы | Найти все элементы по CSS-селектору |
| forEach | для каждого | Повторить действие для каждого элемента |
| dataset | данные элемента | Прочитать значение из data-атрибута |
| toLowerCase | в нижний регистр | Сделать буквы строчными |
| includes | содержит | Проверить наличие текста |
| hidden | скрытый | Скрыть элемент на странице |

## Как устроены упрощённые главные страницы

- HTML задаёт заголовки, подписи, поля ввода и кнопки.
- CSS задаёт простой внешний вид.
- JavaScript выполняет действие после нажатия кнопки или ввода текста.
- Формы и расчёты демонстрационные: данные не отправляются на сервер.
- В заголовках страниц сохранены SEO-метаданные исходных проектов. Встроенные стили и сценарии нужны, чтобы главные страницы были короткими и понятными.

## Что важно сказать на защите

«Это учебные демонстрационные сайты. HTML отвечает за структуру, CSS — за внешний вид, JavaScript — за действия пользователя. Расчёты выполняются в браузере. Реальной базы данных и отправки заявок на сервер нет».
