# Аттестационная работа — 11 учебных веб-проектов

## Публикация

- Репозиторий: https://github.com/adminestratorcom/attestation-web-projects
- Каталог GitHub Pages: https://adminestratorcom.github.io/attestation-web-projects/
- Корневой каталог содержит ссылки на все 11 проектов.

## Состав

1. `01_finance` — финансовый калькулятор.
2. `02_cafe` — сайт кофейни.
3. `03_transport` — транспорт и расписание.
4. `04_social` — социальная помощь.
5. `05_education` — образовательный центр.
6. `06_health` — медицинский центр (учебная демонстрация).
7. `07_culture` — культурная афиша.
8. `08_sport` — спортивный клуб.
9. `09_shop` — каталог интернет-магазина.
10. `10_service` — бытовые услуги.
11. `11_portfolio` — портфолио проектов.

В каждом проекте есть `index.html`, `about.html`, `contacts.html`, `style.css`, `script.js`, `robots.txt`, `sitemap.xml` и `DESIGN.md`. Всего 33 страницы проектов и корневая страница каталога, 34 HTML-страницы.

## Что реализовано

- Адаптивная вёрстка на HTML и CSS с Flexbox/Grid и медиазапросами.
- Многостраничная навигация, формы с браузерной валидацией и интерактивные элементы JavaScript.
- В зависимости от проекта: калькуляторы, фильтры, корзина, расписание, тесты, таймеры, аккордеоны, галерея, поиск и отзывы.
- Портфолио с поиском, переключением темы и появлением карточек при прокрутке.
- Проект 10 дополнен недостающими `style.css` и `script.js` в ходе финальной технической проверки.

## SEO и аналитика

- Для 34 HTML-страниц проверено наличие `title`, `description`, canonical, Open Graph, Twitter Card и JSON-LD Schema.org.
- Подготовлено семантическое ядро на основе предоставленных значений Яндекс Wordstat: `SEO-semantic-core.md` и `SEO-SEMANTICS.md`.
- Корневой `robots.txt` указывает на `sitemap.xml`; корневая карта содержит 34 canonical URL. У каждого проекта есть свой `robots.txt` и sitemap из трёх URL.
- Подключены счётчик Яндекс Метрики и Google Tag Manager; тег Google Analytics 4 настроен через GTM. Подключение тега ранее проверялось через Tag Assistant и отчёт реального времени GA4. Это не является доказательством органической индексации или роста поискового трафика.

## Важные ограничения

Это учебные демонстрации. Формы проверяют введённые данные в браузере, но не отправляют заявки на сервер. Бронирования не являются реальными, расписания и цены демонстрационные, корзина не оформляет заказ. Медицинские блоки не диагностируют заболевания. Для коммерческого использования понадобятся серверная часть, защита персональных данных, реальные источники информации и согласованные контактные данные.

## Подготовка локального запуска

Откройте корневой `index.html` в браузере или откройте папку репозитория в VS Code и запустите через Live Server. Сохраняйте структуру папок, поскольку ссылки между проектами относительные.

## Автоматическая техническая проверка

В репозитории настроена GitHub Actions-проверка `.github/workflows/website-qa.yml`. Она запускается при push, pull request и вручную через вкладку Actions.

Проверяющий скрипт `scripts/validate_sites.py` проверяет:
- наличие корневой страницы каталога и 33 страниц проектов;
- наличие title, meta description, canonical и JSON-LD на каждой HTML-странице;
- существование локальных CSS- и JavaScript-файлов, на которые ссылаются страницы;
- корректность XML и состав URL в корневом sitemap.xml и картах каждого проекта;
- наличие robots.txt и ссылок на соответствующие sitemap.xml.

Эта автоматическая проверка анализирует файлы репозитория. Она не заменяет визуальное тестирование в браузере, проверку реальной отправки форм, тестирование на мобильных устройствах и подтверждение индексации в Яндекс Вебмастере или Google Search Console. Результат запуска см. во вкладке Actions.

## Ограничения демонстрационных функций

Интерактивные элементы учебных сайтов предназначены для демонстрации клиентской логики. Формы не следует считать полноценной серверной системой приёма заявок или бронирования, если для конкретной функции не подключены сервер и база данных.
