Главные страницы содержат соответствующие тематике заголовки, разделы и инструменты: калькулятор вклада, меню и бронирование, расписание и поиск рейсов, блоки социальной помощи, курсы и расписание, запись к врачу, афиша и билеты, спортивные инструменты, каталог и корзина, калькулятор бытовых услуг, каталог портфолио.

В мета-теге keywords главных страниц уже присутствуют тематические фразы для всех 11 проектов. В meta description также отражены основные функции каждой страницы.

## Что ещё требуется

4. Не использовать неподтверждённые частотности и не обещать реальные услуги: сайты являются учебными демонстрационными проектами.

## Уточнение по частотности для проектов 08–11 (12.11.2026)

Выбранный регион: **Россия — все регионы**.

Проверка возможности получить метрики через подключённый OpenSEO выявила ограничение источника: используемый им DataForSEO не поддерживает данные по России и Беларуси. Поэтому его показатели нельзя использовать как частотность Яндекс Wordstat для выбранного региона.

Для проектов 08–11 оставлены ключевые фразы для ввода в Яндекс Wordstat, но числовая частотность остаётся **неизвестной до получения данных непосредственно из Wordstat**:

- Спорт: спортивный клуб; расписание тренировок; фитнес тренировки; абонемент в спортзал.
- Магазин: каталог товаров; интернет-магазин; товары для дома; каталог товаров с фильтрами.
- Бытовые услуги: бытовые услуги; ремонт одежды; ремонт обуви; химчистка.
- Портфолио: портфолио веб-разработчика; примеры веб-сайтов; учебные веб-проекты; портфолио сайтов.

Не заменять эти значения оценками Google, DataForSEO или других сервисов. Для завершения требуется выгрузка/доступ к Яндекс Wordstat с регионом «Россия» и одинаковым типом соответствия запросов.
