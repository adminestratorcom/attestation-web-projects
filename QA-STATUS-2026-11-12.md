## Что автоматизация проверяет

1. Наличие 34 ожидаемых HTML-страниц.
2. Наличие title, meta description, canonical и JSON-LD.
3. Существование локальных CSS- и JavaScript-файлов, подключённых из HTML.
4. Корректный XML и ожидаемый состав URL в корневой и проектных картах сайта.
5. Наличие robots.txt и правильных ссылок на sitemap.

## Что пока не подтверждено

- Успешный результат первого запуска GitHub Actions: его нужно посмотреть во вкладке Actions после завершения workflow.
- Визуальная проверка всех 11 сайтов в настольном и мобильном браузерах.
- Полное ручное прохождение интерактивных сценариев из `TEST_CHECKLIST.md`.
- Реальная отправка данных из форм на сервер: формы учебных проектов следует считать демонстрационными, пока не подключена серверная часть.
- Актуальность опубликованной версии каждой страницы на GitHub Pages: доступ к опубликованным страницам в ходе этой проверки не подтвердился.
- Индексация поисковиками: её можно подтверждать только данными Яндекс Вебмастера и Google Search Console, а не наличием sitemap или поиском `site:`.

## Следующие действия

1. Открыть GitHub → Actions → Website QA и дождаться зелёного статуса.
2. Проверить все сайты в браузере на компьютере и телефоне.
3. Пройти сценарии из `TEST_CHECKLIST.md`, отмечая результат и дефекты.
4. Проверить индексацию через подключённые панели веб-мастеров.
